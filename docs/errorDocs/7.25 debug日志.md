### import 大小写伪 Red

- 失败命令：`python -m pytest -q`
- 首次结果：收集阶段 `ModuleNotFoundError: No module named 'Agent'`。
- 原因：Git 记录包目录为 `Agent/`，但 Windows 工作树物理目录为 `agent/`；按 Linux CI 契约使用 `import Agent` 后暴露大小写不一致。
- 最小修正：将物理目录大小写归一为 `Agent/`，并将根入口和测试导入统一为 `Agent`。
- 二次结果：收集阶段 `ModuleNotFoundError: No module named 'Agent.Provider'`。
- 原因：Git 记录模块为 `Agent/Provider.py`，但 Windows 工作树物理文件名为 `provider.py`。
- 最小修正：将物理文件名归一为 `Provider.py`，并把现有相对导入统一为 `..Provider`。
- 验证命令：`python -c "import Agent; from Agent.Provider import ROOT; print(Agent.__file__, ROOT)"`
- 结果：成功导入仓库根下的 `Agent` 包和 `Agent.Provider`。
