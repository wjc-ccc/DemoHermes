### 1. AgentLoop都做了什么？   -- 核心从上下文构成角度分析 session、tool、retry、interrupt

- 查看有哪些**model provider可用** --- model_register
- 查看有哪些 **skill/tool 并加载**可用  --- tool/skill _ register
- 设定**api稳定性相关参数/函数**  --- timeout 、max iteration 、max retries
- **处理打断**相关能力 --- _interrupt
- **前端展示/message bus输送接口函数** --- _emit
- **工具执行调用函数** --_execute_tool

### 2. 一次Agent loop run 流程是什么？

1. 首先**传入参数为gateway给到的session和message**
2. 设定**turn id 然后emit出当前已经开始的状态到message bus**
3. **组装为最终的session**上下文
4. 然后**组建全部的上下文** context builder
5. 然后通过**emit函数 把对应的识别信息发给message bus 用于前端展示** 或者 输出给用户
  ```python
              self._emit(
                  "llm_request", turn_id, session, session_key,
                  iteration=iteration, **stats,
              )
  ```
6. **最终调用带有retry等托底方式进行对话**（max iteration 循环 有问题就 retry 没问题返回 到次数结束）
  ```python
  response = self._chat_with_retry(messages)
  ```
7. **判断最终输出是否含有工具调用flag 有的话加入session 对应的message 和 tool call 然后调用工具**
8. **最终输出文本的话 结束 放到session中 然后返回TurnResult对象**
