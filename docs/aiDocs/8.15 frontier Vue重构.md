# Frontier Vue 前端（2026-08-15）

## 怎么跑

```text
# 终端1 — 后端
.venv/Scripts/python.exe main.py
# Debug 页需要：
.venv/Scripts/python.exe main.py --enable-memory-debug

# 终端2 — 前端开发
cd frontier
npm install
npm run dev
```

生产静态托管：`npm run build` 后 `python frontier/main.py`（托管 `dist/`）。

## 配置

唯一配置入口：[frontier/src/config.ts](../../frontier/src/config.ts)

- `backendHost` / `backendPort`：后端地址（Vite proxy 也读这里）
- `enableMemoryDebug`：是否挂 Memory Debug 路由与顶栏入口
- `enableManagerRoute`：是否暴露 Manager 占位页
- `chatId` / `userId`：当前 frontier 身份
- `debugPageSize`：Debug 列表分页大小

前端为 **Vue3 + TypeScript**（目录结构不变，源码为 `.ts` / `.vue` lang=ts）。

## API 层

所有后端请求只经 `frontier/src/api/*`；每个导出函数注释「目的 / 得到」。

| 路径 | 说明 |
|------|------|
| POST /api/chat | 同步一轮对话 |
| POST /api/reset | 新会话 |
| GET /api/events | LoopEvent SSE |
| GET /api/status | 顶栏状态 |
| GET /api/debug/memory/session | flag：SQLite 只读 |
| GET /api/debug/memory/hot | flag：profile + MEMORY + daily/*.md |

Debug 页 Tab：Session / Messages / Tool Calls / **Profile** / **Memory** / **Daily**（一表一页，列表可分页）。

右栏步骤：`utils/emitMapper.ts` 按 `LoopEvent.type` 匹配模板。
