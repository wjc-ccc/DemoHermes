# DemoCursor 模块架构总览

> 依据 2026-09-28 工作区代码整理。本文描述已经接线的运行路径；`docs/aiDocs/` 是方案和阶段记录，不能代替当前实现。

## 1. 一轮请求如何运行

```text
CLI / Frontier HTTP / 飞书 / QQ / 微信
  → Channel：平台消息、附件 → InboundEvent
  → Gateway：入站队列、会话键、同会话锁、Session
  → MemoryContextLoader.freeze：本轮固定的 MemorySnapshot
  → AgentLoop：冻结 SkillSelection，反复执行 Precision → Model → Tool
  → Gateway：commit_turn；提交成功后通知 Memory Reviewer / Skill Evolution
  → 出站队列 → Channel → 用户
```

启动装配点是 `agent/main.py:build_gateway`，进程入口是根目录 `main.py`。默认 HTTP 模式接 `frontier/`；`--cli` 启动终端模式。`--no-use-memory` 会改用进程内会话存储，同时不装配持久化记忆及相应的进化旁路。

| 跨模块对象 | 生产者 → 消费者 | 定义 |
| --- | --- | --- |
| `InboundEvent` / `OutboundReply` | Channel ↔ Gateway | `agent/core/types.py` |
| `Session` / `Message` / `ToolCall` | Gateway、Loop、Store | `agent/core/types.py` |
| `MemorySnapshot` | Memory → Precision | `agent/core/memory/memory_snapshot.py` |
| `PrecisionResult` | Precision → Loop | `agent/core/precision/percision_types.py` |
| `TurnResult` / `TurnRecord` | Loop → Gateway → Store/旁路 | `agent/core/types.py`、`agent/core/memory/types/memory_source_types.py` |

## 2. 七个能力模块

| 模块 | 当前代码与入口 | 主要职责 | 交给下一模块的结果 |
| --- | --- | --- | --- |
| **感知** | `agent/channel/` 的 `BaseChannel.parse_to_InboundEvent`、`media.py`；`agent/core/building_messages.py` | 接收各平台消息，去重和附件处理，统一文本、来源及 `ContentPart` | `InboundEvent`，随后转成用户 `Message` |
| **推理** | `agent/core/agent_loop.py:run_turn`、`agent/core/precision/percision_engine.py:build`、`agent/model/` | 固定技能选择，按预算装配上下文，调用模型，判断继续调用工具还是给出回复 | 模型回复、工具请求或 `TurnResult` |
| **执行** | `agent/tools/registry.py:dispatch`、各 Tool、`agent/skills/skill_tool.py` | 执行模型请求，返回 `ToolCallResult`；Loop 记录 `ToolCall` 并回注结果 | 工具结果进入下一次模型调用 |
| **反思** | `agent/core/memory/memory_batch_reviewer.py`、`agent/evolution/llm_reflector.py`、`skill_evolution.py`、`agent/eval/` | 已提交轮次的记忆提炼与校验；从轨迹提出 Skill 草案、补丁；隔离评测与回放 | 记忆提案、Skill 草案或评测报告 |
| **记忆** | `agent/core/memory/`、`agent/storage/sqlite/`、`agent/tools/memory_*` | 冻结本轮上下文，按 scope 检索原文和卡片，管理手册/卡片版本，提交持久化事实 | `MemorySnapshot`、检索结果、下一轮可见的记忆 |
| **治理** | `memory_scope.py`、`memory_validator.py`、`percision_engine.py`、`skill_gate.py`、`agent/eval/`、`agent/storage/sqlite/audit_store.py` | 控制作用域、来源校验、上下文预算、Skill 晋升门槛、审计与可观测性 | 校验结论、Trace、审计记录或拒绝原因 |
| **协作** | `agent/gateway/`、`agent/channel/`、`agent/core/event_bus.py` | 多渠道共享一个 Gateway；不同会话并行、同会话串行；通过事件和提交后钩子连接后台工作 | 路由到目标 Channel 的回复及旁路通知 |

这些名称是能力视角，不全是同名 Python 包。例如“反思”横跨 Memory Reviewer、Evolution 和 Eval；“治理”分散在读写关口。Task 三态工作台已下线；当前“协作”主要是渠道、会话和后台工作的协同。

### 感知：外部输入进入统一契约

- `BaseChannel` 定义 `start/stop`、入站解析和出站投递。`CliChannel`、`FrontierChannel`、`FeishuChannel`、`QQChannel`、`WechatChannel` 是具体适配器；平台连接由 `agent/channel/registry.py` 按配置自动启动。
- `ContentPart` 能承载图片和文件。渠道将附件保存到 `data/channel/media/`，单件上限 20 MiB；模型输入由 `agent/model/media_messages.py` 根据模型 `supports_images` 决定是否附带图像。文件正文、语音和视频语义理解尚未进入这条主链。
- `Gateway.build_message` 委托 `build_user_message`，把传输事件转成 Session 中的对话事实。平台字段应在 Channel 转换，不进入 Loop。

### 推理：上下文与模型循环

- `AgentLoop.run_turn` 给一轮请求分配 `turn_id`，添加用户消息，冻结一次 Skill 选择；每轮迭代调用 `PrecisionBuilder.build`，再由模型适配器 `chat`。模型返回工具调用时执行并回注；纯文本时结束，达到 `max_iterations` 则返回未完成结果。
- Precision 是上下文的唯一构建主链：加载系统提示、技能、Memory 快照、当前请求和历史；生成 `ContextItem`，分级、压缩或延迟暴露，再构建模型消息。历史过长时使用有覆盖范围的 Anchor；预算不足或 Anchor 无法安全压缩会返回明确错误。
- `agent/model/registry.py` 提供模型选择，`baseStructure.py` 定义模型回复契约。模型调用有有限重试；模型是否能看图由适配器能力决定。

### 执行：工具和技能

- Loop 通过 `ToolRegistry.dispatch` 执行模型指定的工具。默认装配注册计算器、`use_skill`、`skill_manage`；开启记忆时再注册 `memory_search`、`memory_read`、`memory_edit`。`agent/tools/` 中存在的 bash/file 实现不能仅凭文件存在就视为默认开放工具。
- 工具结果被记录成 `ToolCall` 并作为 `role=tool` 消息回注。`memory_edit` 的卡片变更在本轮提交时与对话事实同一事务落库；提交失败时 Gateway 会标记错误。
- Skill 是 `SKILL.md` 经验文本：Registry 按查询选摘要，模型需要正文时调用 `use_skill`。生成型 Skill 经 Repository 管理状态与版本；项目目前没有 `plugin/` 运行时加载器。

### 反思：事后提炼与质量反馈

- Gateway 的 `commit_turn` 成功后才触发旁路 `EvolutionScheduler.notify`。`MemoryReviewWorker` 由作业调度器分批取已完成轮次，`MemoryExtractor.extract_batch` 生成提案，`MemoryBatchReviewer` 核对来源和逐字证据，Validator 再校验内容，Committer 写入卡片与 Trace。
- `SkillEvolution.consider` 使用 `TurnFacts`、轨迹蒸馏、模型 Reflector、Creator 和 Optimizer 提出 Skill 草案或补丁。`SkillLifecycleGate` 要求回放结果满足晋升条件；`build_gateway` 当前没有向 `SkillEvolution` 注入 `runner_factory`，因此自动生成的草案不会在生产装配中自动晋升。
- `EvalRunner.run(suite)` 在隔离 case 环境回放 Gateway 轮次；`agent/eval/` 还含 shadow/replay/ablation。这些是评测能力，不等于每轮回复前都有一个自动自我批评步骤。

### 记忆：本轮快照与跨轮沉淀

- `MemoryScope` 从 `SessionSource` 推导个人或群聊归属，并生成稳定 `storage_key`。Policy、Project、User、Task、Scratchpad 是信息归属层，不是五个都自动常驻提示词的开关。
- 每轮执行前，`MemoryContextLoader.freeze` 读取 Policy、项目文档、当前用户的有界 `MEMORY.md` 及相关经验卡，形成不可变 `MemorySnapshot`。`MemoryRetriever.recall` 最多注入三张关键词命中的经验卡，其他原文按 `memory_search`、`memory_read` 获取。
- 当前用户卡片有 `profile`、`stable_preference`、`ongoing_fact`、`reusable_experience`。手册和卡片通过后台维护/同步作业保持一致；用户显式记忆修改走 `memory_edit`。`RuntimeStorage.open` 统一初始化 SQLite 及 Session、Memory、Job、Trace、Audit 等 Store。
- 具体的批次、版本冲突、tombstone 与检索规则见 [Memory 运行链路](recognitionDocs/memory.md) 和 [SQLite 与 Memory 存储](sqlite-memory-storage.md)。

### 治理：约束落在执行关口

- **输入与权限**：Channel 校验平台载荷及附件；Memory 工具的 `_scope` 由 Loop 注入，模型不能自选作用域。Reviewer 只接受本批次可追溯的消息/工具证据。
- **资源与变更**：`ContextBudget` 和 Precision 控制模型输入；Memory 手册有长度和版本校验；Skill Repository 校验修订并写审计，晋升由 Replay Gate 控制。
- **观测**：`EventBus` 发布 turn、模型、工具和出站事件；`PrecisionTrace` 与 `MemoryTrace` 分别记录上下文取舍和记忆提炼。Gateway 的 HTTP Debug/Trace 接口及 `frontier/` 可查看状态。运行时可直接观测的字段与模型提案字段应在各自 Trace 中区分。
- 当前并没有覆盖所有工具和渠道的统一策略引擎；治理规则分布在上述关口，新增规则应放在实际执行该规则的模块 Interface 上。

### 协作：会话和后台工作如何配合

- `MessageBus` 有入站、出站两条队列。Gateway 为每个 `session_key` 加锁，同一会话按顺序处理，不同会话可在线程池并行。`ask` 用 `correlation_id` 等待出站结果，HTTP 和 CLI 共用这条路径。
- 持久化路径由 `SqliteSessionStore.commit_turn` 提交后，再通知 Memory Reviewer、Skill Evolution 和环境快照；这样旁路工作读取的是已经落库的事实。`EventBus` 供前端观测及轻量信号收集。
- 跨会话的个人记忆通过相同 `MemoryScope.storage_key` 复用；群聊与个人 scope 分开。`SqliteWorkspaceStore`、叙事与机械状态 Store 已能显式记录计划节点、契约和状态，但普通对话不会自动建立或推进工作台；多 Agent 协作仍需定义委派、权限、交接和结果合并的 Interface。

## 3. 维护时从哪里改

| 需求 | 优先查看 |
| --- | --- |
| 新平台或附件类型 | `agent/channel/`、`agent/core/types.py:ContentPart`、`agent/model/media_messages.py` |
| 模型上下文选择或压缩 | `agent/core/precision/`、`agent/core/context_budget.py` |
| 工具或技能 | `agent/tools/`、`agent/skills/`、`agent/main.py:build_gateway` |
| 记忆检索、提炼或编辑 | `agent/core/memory/`、`agent/storage/sqlite/`、`agent/tools/memory_*` |
| Skill 自进化和质量门 | `agent/evolution/`、`agent/eval/` |
| 会话并发、提交、出站 | `agent/gateway/gateway.py`、`agent/gateway/message_bus.py` |
| Debug 视图和 Trace | `agent/gateway/http_api.py`、`agent/gateway/trace_modules.py`、`frontier/src/views/` |
