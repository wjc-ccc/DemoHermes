# DemoCursor 模块架构总览

从 [AgentRuntime 运行架构](runtime-architecture.md) 阅读真实入口、职责、数据、事务和生命周期。

    main → AgentRuntime
             ├─ ModelRegistry / RuntimeStorage / Skills
             ├─ MemoryBuilder
             ├─ ToolHandler → ToolDispatch
             │    └─ core/action：账本、Guard、计划、工件与恢复
             ├─ PerceptionBuilder → AgentLoop
             └─ Gateway → Channel / HTTP

core 是 Runtime 内部能力。Gateway 管消息和会话，Loop 管迭代，Handler 管审批分配，Dispatch 管执行，Store 管事务。Action 实现位于 core/action，共享类型位于 types/action；会话统一使用 SQLite。

Memory 与普通技能管理保留，Skill Evolution 已删除。没有工作台或 SqliteWorkspaceStore；计划与恢复属于 Action。

详细接口见 [架构认知索引](recognitionDocs/README.md)，历史记录见 [文档目录](README_docs.md)。
